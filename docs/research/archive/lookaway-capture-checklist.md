# LookAway Capture Checklist

Use this to audit interaction patterns and requirements, not to reproduce LookAway’s artwork, wording, animations, or trade dress.

## Capture method

For each item:

1. Take a screenshot at native resolution.
2. Record the action that opened it.
3. Record defaults and every available option.
4. Note keyboard behavior, animation, sound, and timing.
5. Note what happens to the active timer while the screen is open.
6. Record what felt excellent, confusing, or annoying.

Make one short screen recording of a full warning → grace → break → return cycle, including the pointer and sound if possible.
