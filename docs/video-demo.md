# Video demo controls

The local filming setup binds:

- `Super + Alt + 8`: advance to the next deterministic demo fixture
- `Super + Alt + 9`: leave demo mode and restore the real schedule

The cycle is:

1. Away
2. Recent activity
3. Meeting
4. Microphone
5. Camera
6. Screen sharing or recording
7. Video
8. Generic media
9. Fullscreen
10. Dictation
11. Due soon
12. Warning
13. Final warning
14. Casual break
15. Balanced break
16. Hardcore break
17. Long break
18. Statistics
19. Paused
20. Snoozed
21. Real schedule restored

Use fixtures for context detection, countdown thresholds, warnings, and break
enforcement. Demonstrate keyboard navigation, settings, theme integration,
snooze actions, statistics, and ordinary panel use against the real interface.

Demo mode snapshots the real schedule and configuration on entry. Every fixture
starts from that saved configuration, and leaving demo mode restores both.
